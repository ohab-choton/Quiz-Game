# Quiz-Game

## Description
This is a quiz game project.

## Features
- Developed a RESTful API-based quiz platform using Django REST Framework and use streamlit(for frontend).
- Features: Quiz & question management, user authentication, answer validation, result tracking, leaderboard.
- Role-based access for admin (quiz creation) and users (quiz attempt)
- show wrogng answer and correct answer
- User-friendly interface
